About CostIQ

CostIQ is an enterprise cost spend analysis platform built for GlobalBite Foods Inc., tracking procurement and promotional spend across 5 global regions.

Technology Stack
  • Spring Boot 3.5
  • Spring Security 6 / OAuth2 PKCE
  • Keycloak 26 IdP
  • Thymeleaf 3 + Bootstrap 5
  • Spring Data JPA (validate only)
  • MySQL 8.x
  • Chart.js 4.x Dashboards
  • DBA-owned DDL (no app schema rights)
