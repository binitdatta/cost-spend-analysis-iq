Architecture

Flask ChatBot (Port 5001)
  • Keycloak 26 PKCE authentication
  • Claude claude-opus-4-5 AI responses via Anthropic API
  • SSE token-by-token streaming
  • 11 live CostIQ REST API calls per chat turn
  • Apache POI Excel export via Spring Boot
Spring Boot (Port 8085)
  • Dual security: PKCE UI + JWT Bearer API
  • 11 REST JSON endpoints + Excel export
  • Food, Packaging, Toy, Marketing domain
  • Spring Data JPA / MySQL 8 / Hibernate 6
  • Apache POI 5.3 — augmented 8-sheet workbook
Keycloak 26 (Port 8080)
  • Realm: costiq-realm
  • PKCE S256 enforced — no client secret
  • Shared by Spring Boot UI and Flask ChatBot
  • JWT Bearer token validation for REST APIs
MySQL 8 (Port 3306)
  • Schema: costiq_db
  • 17 tables — regions, countries, suppliers, campaigns…
  • DBA-owned DDL — Hibernate validate only
  • Rich seed data — 38 food + 23 packaging + 26 toy entries
Enterprise-Grade Security — Protected by Keycloak 26 OAuth2 PKCE. All chat sessions are authenticated. No cost data is accessible without a valid token.
